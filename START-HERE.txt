WASP BUDDY — RUN ON YOUR COMPUTER

1. Unzip the whole prepared local-app folder.
2. Install Node.js 20.11 or newer if it is not already installed.
3. Windows: open start-local.cmd.
   Mac: open start-local.command (use Open from its right-click menu if needed).
   Linux / Terminal: run node start-local.mjs in this folder.
4. Keep the terminal window open while using the app.
5. Open camera → Use device camera → Allow.
6. Choose a photo opens existing files. It is not the live-camera button.
7. Tap SCAN to check one image. Photos are analysed on this device.
8. Grown-ups → Test sound plays a chime and requests Buzz's voice.

The prepared ZIP includes the model and runtime. From a Git source checkout,
run npm ci and npm run build before starting the app.

No recognition key or paid service is needed in the default app.
It may get a photo wrong, miss a wasp, and cannot measure one metre.
It cannot tell whether an area is safe. Keep a grown-up nearby.
The app opens directly on the real camera screen. There are no pretend alert buttons.

If the camera was denied, allow it in your browser's site settings.
If sound is silent, check device volume, silent mode, and browser sound settings.
Running the server in a remote workspace does not start it on your own computer.
